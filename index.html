Voice Agent Support

Voice Agent is an iPhone app for talking to the AI model, speech services and MCP tools you set up yourself. It has no account and no server of its own.

Contact

Write to martinh30@gmail.com. Please say which service you use and what the app showed. Never send your API keys.

Getting started

  1. Open Settings, then LLM servers, and add a server with its API key.
  2. Tap Test connection, tap a model and choose Use for main agent.
  3. Type a message, or tap the microphone and speak.

Common problems

Your own server does not respond. The iPhone must be able to reach its address, including over a VPN if the server needs one.

Nothing is heard or written. Check microphone and speech recognition access in iOS Settings, then try the service with Test speech recognition in its settings.

Apple's model is not available. Turn on Apple Intelligence in iOS Settings and wait for its download. Apple's language rules apply.

Podpora Voice Agent

Voice Agent je aplikace pro iPhone, se kterou mluvíte s AI modelem, hlasovými službami a MCP nástroji, které si sami nastavíte. Nemá účet ani vlastní server.

Kontakt

Napište na martinh30@gmail.com. Uveďte prosím, jakou službu používáte a co aplikace ukázala. API klíče nikdy neposílejte.

Začínáme

  1. Otevřete Nastavení, LLM servery a přidejte server s jeho API klíčem.
  2. Klepněte na Test connection, na model a zvolte použití pro hlavního agenta.
  3. Napište zprávu, nebo klepněte na mikrofon a mluvte.

Časté potíže

Vlastní server neodpovídá. iPhone musí na jeho adresu dosáhnout, případně i přes VPN, pokud ji server potřebuje.

Aplikace nic neslyší ani nepíše. Zkontrolujte přístup k mikrofonu a rozpoznávání řeči v Nastavení iOS a službu vyzkoušejte tlačítkem Vyzkoušet převod řeči v jejím nastavení.

Model Apple není dostupný. Zapněte Apple Intelligence v Nastavení iOS a počkejte na stažení. Platí pro něj jazyková pravidla Applu.
